🇬🇧 README (English)
🧾 Easy Free CV Builder — Open Source Resume Generator

An open-source CV/Resume builder built with Next.js + Tailwind CSS, designed to let anyone create and export a professional PDF résumé — completely free and offline.
It’s fast, private, and flexible: no tracking, no paid plans, no servers.

✨ Features

💾 Import/Export JSON data for backups or sharing

📄 Direct PDF export with a clean HTML template

🔒 100% client-side — no data ever leaves your browser

💡 Why

Most online CV tools are paywalled or require account creation.
This project was built to provide a free and transparent alternative that anyone can use or self-host.

It’s a project by Alessandro Iannacone
 — DevOps Engineer passionate about automation, infrastructure, and open-source simplicity.

🚀 Quick Start
# Clone the repository
git clone https://github.com/username/easy-free-cv-builder.git
cd easy-free-cv-builder

# Install dependencies
npm install

# Run in development
npm run dev


Then open http://localhost:3000
 and start building your CV!

🧰 Tech Stack

Next.js 14+ (App Router)

React + Tailwind CSS

TypeScript

HTML-to-PDF generator

100% client-side storage and rendering

📦 Export / Import

You can export your CV data as a JSON file and re-import it anytime.
This makes it easy to version, share, or backup your résumé.

✨ Funzionalità

💾 Import/Export JSON per backup o condivisione
